# Aura Demo

**Aura** — умный помощник, который находит лучшие предложения в сети: товары по честному сравнению и услуги с проверкой скрытых доплат. Это **демонстрационный прототип** (DEMO_MVP): всё работает «по-настоящему» на глаз, но данные — примеры.

Идея в одном предложении: вы пишете запрос одной фразой — за него параллельно работает целая команда (исследователи, поиск по магазинам, аналитики, ревизоры), и вы видите её работу в прямом эфире, а потом получаете понятную и красивую выдачу.

---

## Как запустить

Нужен Node.js 18 или новее.

```bash
npm install        # установка зависимостей
npm run dev        # режим разработки → http://localhost:5173
npm run build      # продакшн-сборка в папку dist/
npm run preview    # просмотр собранной версии → http://localhost:4173
```

## Демо-сценарии (что проверить)

Главная страница принимает любой текст. Попробуйте:

1. **Точный товар** — `Honor Magic 7 Pro`
   Поиск без вопросов → параллельная работа: магазины отвечают по одному, исследователь читает свежие обзоры, аналитик сравнивает, ревизор перепроверяет → главная карточка «Выбор Aura» с честным расчётом и баллами → ещё 4 варианта → 4 раскрывающихся дашборда (динамика цены, средняя по рынку, проверка надёжности, полное сравнение в таблице).

2. **Категория** — `Беспроводные наушники до 3 000₽`
   Сначала 3 коротких вопроса кликабельными карточками → ваши ответы превращаются в чипы → подбор из 6 вариантов с главным.

3. **Подарок** — `Подарок парню на 23 февраля`
   Вопросы про возраст, интересы и бюджет → три параллельные «дорожки-направления» в процессе → финальная подборка: главная идея + 3 направления по 3 идеи.

4. **Услуга** — `Остеклить балкон`
   Вопросы про объём, сроки, бюджет → карточка «Поняла задачу» → компании присылают цены одна за другой на глазах → сравнение с плашками «возможны скрытые доплаты» → «Рекомендация Aura» → кнопка «Выбрать» показывает, как откроется контакт.

Ещё что стоит посмотреть:

- **Подсказки**: начните вводить на главной — появятся варианты из 4 групп; работают стрелки ↑/↓, Enter, Esc, а Ctrl/⌘+K фокусирует строку.
- **Фразы-сомнения**: на главной по экрану плавают живые мысли покупателей («А если это не оригинал?», «Как найти лучшую цену?») — часть из них помечается решённой ✓.
- **Сфера** справа вверху: клик → добавление на экран «Домой» (PWA).
- **Темы**: справа вверху — Система / Светлая / Тёмная, выбор запоминается.
- **Баллы**: /points — баланс, честное объяснение (баллы бесплатны), рефералка «+1000 за друга», история.
- **Страница исполнителя**: /smart-link/demo — приём цены от компании без регистрации («нулевое трение»).

**Ускорить показ:** добавьте к адресу `?fast=1` — анимация процесса сожмётся до ~2 секунд. Есть и кнопки ускорения прямо в панели процесса.

## Где лежит что

| Что | Где |
|---|---|
| Списки из 80 запросов, фразы-сомнения | `src/data/suggestions.ts` |
| Mock-данные: товары, категории, подарки, услуги | `src/data/catalog.ts`, `src/data/offers.ts` |
| Сценарии «работы команды» параллельными событиями | `src/data/scripts.ts` |
| Классификатор запроса (4 типа + fallback) | `src/lib/classify.ts` |
| Движок поиска (вопросы → процесс → результаты) | `src/stores/flow.ts` |
| Главный экран (сфера, фразы-сомнения, ввод) | `src/features/home/` |
| Выдача результатов (бенто, дашборды, тултипы) | `src/components/results/` |
| Панель «Что я сейчас делаю» | `src/components/ProcessPanel.tsx` |
| Дымовые проверки данных и сценариев | `scripts/smoke.ts`, `scripts/flow-check.ts`, `scripts/render-check.tsx` |

Проверки можно прогнать так: `TSX_TSCONFIG_PATH=tsconfig.app.json npx tsx scripts/smoke.ts` (и аналогично для остальных двух).

## Что НЕ входит в демо (осознанно)

- Реальная оплата, реальные CPA-интеграции, реальный парсинг магазинов.
- Реальные рассылки компаниям, звонки, чаты — показан только принцип.
- Реальный сбор персональных данных (ничего никуда не отправляется).
- PNG-иконки PWA — сейчас SVG (рабочие, но для полноценной установки на iOS позже нужны PNG 192/512).

## Допущения, принятые в демо

1. Слово «агент» нигде в интерфейсе не используется — роли названы по-человечески: исследователи, поиск по магазинам, аналитики, ревизоры.
2. «Кэшбэк» не использован: в честном расчёте строка называется «Баллы Aura» — так не путается с комиссией.
3. Рекомендация по услуге — не самая дешёвая компания, а лучший баланс цены, рейтинга и гарантии (так честнее).
4. Изображения товаров — стильные градиентные заглушки с иконками: чужие фото и логотипы сознательно не используем.
5. Тяжёлый 3D (Three.js) заменён на лёгкую CSS-сферу + aurora-фон: трендово для 2026 и на порядок легче по весу.
6. Все числа в процессе правдоподобны и детерминированы: один и тот же запрос всегда показывает одну и ту же историю и результат — они связаны между собой.
