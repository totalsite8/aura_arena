# Aura Demo

Aura — умный помощник: вы пишете, что нужно, а она сама уточняет, ищет, сравнивает и показывает лучший вариант. Это демо-прототип. Поиск в интерфейсе бесплатный. Баллы — бесплатный бонус.

## Как запустить

Нужны Node.js 20+ и npm.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173).

Другие команды:

```bash
npm run build      # сборка
npm run preview    # посмотреть сборку
npm run typecheck  # проверка типов
```

Ускорить анимации поиска: добавьте `?fast=1` в адрес, например `/search?q=Honor%20Magic%207%20Pro&fast=1`.

## Что проверить

1. **Точный товар** — `Honor Magic 7 Pro`  
   Сразу идёт поиск, затем блок «Выбор Aura», ещё варианты и раскрывающиеся блоки (цена, надёжность, сравнение).

2. **Категория** — `Беспроводные наушники до 3 000₽`  
   Несколько коротких вопросов карточками, затем подборка.

3. **Подарок** — `Подарок парню на 23 февраля`  
   Вопросы, затем несколько направлений с главным вариантом в каждом.

4. **Услуга** — `Остеклить балкон`  
   Вопросы, описание задачи, ответы компаний, пометки про доплаты, кнопка «Выбрать».

Подсказки в строке ввода можно листать стрелками, выбрать Enter, закрыть Esc.

Также:

- тема: система / светлая / тёмная (запоминается);
- шар на главной — предложение добавить Aura на экран;
- баллы: меню с монетами или `/wallet`;
- страница для компаний без кабинета: `/smart-link/demo`.

Ещё примеры запросов лежат в подсказках: точные модели, подборы, подарки и услуги (по 20 штук).

## Где данные

Демо-данные в папке `src/data`. Никуда в интернет за товарами демо не ходит.

## Что это не умеет

- настоящей оплаты нет;
- писем и сообщений компаниям нет;
- живых магазинов и обновления цен нет;
- личные данные никуда не отправляются.

Кнопки «Купить» и «Открыть контакт» показывают аккуратный демо-экран.

## Допущения в этом демо

- Курс баллов: 10 баллов = 1₽ выгоды. Стартовый баланс — 1000 баллов.
- Город в услугах по умолчанию — Москва.
- Шар на главной нарисован на Canvas, без тяжёлой 3D-библиотеки.
- Если запрос не распознан, Aura сначала спросит, как искать.
- В «честном расчёте» выгода показана как «Баллы Aura», без сложных слов.
- Картинки товаров — абстрактные рисунки, не фото магазинов.
