# Aura Demo

Aura — умный помощник: вы пишете, что нужно, а она сама уточняет, ищет, сравнивает и показывает лучший вариант. Это демо-прототип. Поиск в интерфейсе бесплатный. Баллы — бесплатный бонус, они не вычитаются из цены.

## Как запустить

Нужны Node.js 20+ и npm.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173).

```bash
npm run build
npm run preview
npm run typecheck
```

Ускорить обход витрин: `?fast=1`, например `/search?q=Honor%20Magic%207%20Pro&fast=1`.

Навигация: строка поиска всегда сверху после первого запроса. На телефоне внизу — главная, поиск, баллы. Клавиша `/` сразу ставит курсор в поиск.

## Что проверить

1. **Точный товар** — `Honor Magic 7 Pro`  
   Сначала на весь экран идёт живой обход витрин (адреса печатаются, страницы сыплются). Потом сцена складывается: сверху остаются шаги, ниже — «Выбор Aura» и понятные дашборды.

2. **Категория** — `Беспроводные наушники до 3 000₽`  
   Вопросы карточками, затем подборка.

3. **Подарок** — `Подарок парню на 23 февраля`  
   Несколько направлений на одном экране.

4. **Услуга** — `Остеклить балкон`  
   Описание задачи, ответы компаний, пометки про доплаты.

Подсказки в строке: стрелки, Enter, Esc.

Также: темы, шар на главной (добавить на экран), баллы `/wallet`, страница для компаний `/smart-link/demo`.

## Где данные

Демо-данные в `src/data`. В интернет за товарами демо не ходит — витрины имитируются.

## Что это не умеет

- настоящей оплаты нет;
- писем компаниям нет;
- живых магазинов и цен нет;
- личные данные никуда не уходят.

## Допущения

- 10 баллов = 1₽ учёта бонуса. Старт — 1000 баллов. Баллы не вычитаются из цены на карточке.
- Выбор Aura часто не самый дешёвый: оставляем цену как есть и отдельно говорим про надёжность и баллы.
- Город в услугах — Москва.
- Сфера на главной — Three.js, неровная, с протуберанцами.
- Нераспознанный запрос — сначала «как искать?».
- Картинки товаров — схемы, не фото магазинов.

## Тема

Светлая и тёмная собраны как две полноценные поверхности. На широком экране — бенто, на телефоне — те же плитки столбиком.
